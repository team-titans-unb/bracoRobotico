# Robô Bio V1

Primeira versão do seguidor de linha, desenvolvida como trabalho final de FSE.

![Robô Bio V1 — primeira versão do seguidor de linha](../assets/imagens/roboBioV1.png)

## Visão geral

| Item | Definição |
| ---- | --------- |
| Microcontrolador | ESP32 |
| Firmware | ESP-IDF |
| Sensoriamento | Sensores de refletância (leitura da pista) |
| Controle | PID sobre a velocidade dos motores |
| Conectividade | Wi-Fi + MQTT |
| Telemetria | ThingsBoard (tempo real) |
| Ajuste do PID | Manual, com apoio da telemetria |

## Controle

O robô lia a pista com **sensores de refletância** e corrigia a trajetória com **controle PID** sobre a velocidade dos motores, buscando um seguimento estável na faixa.

## Telemetria

O V1 contava com **Wi-Fi** e **MQTT**, enviando telemetria em tempo real ao **ThingsBoard**. Esse fluxo de dados facilitou:

- monitorar o comportamento do robô na pista
- calibrar o PID manualmente
- depurar o sistema à distância

![Dashboard ThingsBoard — telemetria em tempo real do Robô Bio V1](../assets/imagens/thingsboard.png)

## Limitações encontradas

!!! warning "Problemas mecânicos"
    Não foi possível adotar algoritmos bioinspirados para o ajuste automático das constantes de PID: problemas mecânicos recorrentes — **o chassi prendia na manta emborrachada** — exigiram remodelagem estrutural antes de avançar no controle inteligente.

Essa limitação motivou a [V2](v2.md), cujo foco inicial é resolver a mecânica.

## Registros

| Entregável | Status | Observação |
| ---------- | ------ | ---------- |
| Firmware ESP-IDF | Concluído | Loop de leitura, PID e acionamento |
| Telemetria MQTT/ThingsBoard | Concluído | Dashboard em tempo real |
| Ajuste do PID | Manual | Bioinspirado adiado para a V2 |
| Chassi | Substituído | Prendia na manta emborrachada |
