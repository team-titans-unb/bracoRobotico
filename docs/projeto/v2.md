# Robô Bio V2

Segunda versão do robô, com foco em resolver a mecânica que travou a [V1](v1.md).

![Robô Bio V2 — render 3D do chassi](../assets/imagens/renderV2.png)

## Motivação

Visto que os principais problemas do modelo anterior estavam no design mecânico, a ideia do Robô Bio V2 é um **chassi grande o suficiente** para abrigar as mais variadas ideias possíveis:

- microcontroladores de diferentes tipos
- eletrônica em nível de prototipagem
- espaço físico para evoluir sem as limitações de tamanho da V1

## Fabricação

As peças do chassi são impressas em impressora 3D convencional com filamentos acessíveis como **PLA** e **PETG**, suprindo o maior gap do projeto até então, que era a mecânica. O design foi pensado para os objetivos do Robô Bio e para os componentes eletrônicos disponíveis.

## Resumo técnico

| Área | V1 | V2 |
| ---- | -- | -- |
| Chassi | Próprio, compacto | Seis rodas, suspensão articulada |
| Fabricação | — | Impressão 3D em PLA e PETG |
| Computador de bordo | ESP32 | Raspberry Pi 3 |
| Acionamento | — | PCA9685PW (PWM 16 canais, 12 bits) |
| Atuadores | — | 12 servos MG996R (6 rotação contínua + 6 a 180°) |
| Energia | — | Bateria + 4 placas solares |
| Ajuste do PID | Manual | Meta: algoritmos bioinspirados |
